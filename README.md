# PE — Physical Education Interactive Slides

**300 interactive slides** covering all aspects of Physical Education, each with an interactive animation.

## How to Use

Open `index.html` in any modern web browser. No server or build step required.

- **Navigate**: Arrow keys, swipe, or click Prev/Next buttons
- **Jump to topics**: Click the menu icon (☰) to open the topic sidebar
- **Direct link**: Use `#slide-42` in the URL to jump to any slide
- **Interact**: Each slide has a clickable/draggable animation — follow the hint text
